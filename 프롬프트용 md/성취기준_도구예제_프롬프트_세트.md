# 성취기준 기반 HTML 도구 예제 & 프롬프트 세트

## 1. 이 문서의 목적

이 문서는 **2022 개정 특수교육 교육과정 성취기준**에 근거한 HTML 학습 도구를
LLM/에이전트가 자동으로 생성·리팩터링하기 위한 **기본 자료 세트**입니다.

이 문서 하나만 주면 에이전트는:

- 어떤 성취기준을 대상으로
- 어떤 HTML 도구 유형(선택형/짝짓기/배열형/분류형)
- 어떤 예제 패턴(어떤 HTML 파일 스타일)
- 어떤 프롬프트 구조

를 사용해야 할지 스스로 판단할 수 있습니다.

## 3. 도구 유형별 HTML 패턴 요약

`type` 필드는 HTML 도구 유형을 의미하며, 다음 패턴과 연결됩니다.

### 3.1 `radio`  (선택형 도구)

- **대표 기능**
  - 보기 중 1개를 선택 → 정답/오답 피드백 표시
  - 질문 1개 + 보기 3~4개 구조가 기본
- **대표 HTML 예제** (현재 HTML 도구 템플릿 기준)
  - `HTML_도구_실습용/01_국어_radio.html`
  - `HTML_도구_실습용/01_선택형_단어이해.html` (보다 완성도 높은 버전)
- **상호작용 패턴**
  - `data-correct="true"` 속성으로 정답 표시
  - `div.option` 클릭/키보드(Enter/Space)로 선택
  - 하단 `#feedback` 영역에서 결과 메시지 출력

### 3.2 `match`  (짝짓기/매칭 도구)

- **대표 기능**
  - 왼쪽/오른쪽 항목을 선택하여 "짝" 맞추기
  - 직업-하는 일, 단어-뜻, 그림-단어 등 다양한 매칭 가능
- **대표 HTML 예제**
  - `HTML_도구_실습용/20_사회_match.html`
- **상호작용 패턴**
  - 각 항목에 `data-pair="1"` 등 동일 번호로 정답 짝 표시
  - 왼쪽 하나 + 오른쪽 하나 선택 후 "짝 확인" 버튼
  - 맞으면 `.matched` 클래스, 틀리면 빨간 피드백

### 3.3 `drag`  (배열형/순서/재배치 도구)

- **대표 기능**
  - 카드 여러 개를 드래그해서 순서/위치 정렬
  - 하루 일과, 글 순서, 이야기 순서 등 배열 활동에 적합
- **대표 HTML 예제**
  - `HTML_도구_실습용/10_국어_drag.html`
- **상호작용 패턴**
  - 각 카드: `div.item`, `draggable="true"` + `data-order`
  - `checkOrder()`에서 DOM 순서 vs `data-order` 비교
  - `shuffle()` 또는 `reset()`으로 카드 섞기/초기화

### 3.4 `category`  (분류/그룹화 도구)

- **대표 기능**
  - 항목을 여러 카테고리 영역으로 드래그하여 분류
  - 자석에 붙는 물체/안 붙는 물체, 동물 분류, 감정 분류 등
- **대표 HTML 예제**
  - `HTML_도구_실습용/14_국어_category.html`
- **상호작용 패턴**
  - 항목: `data-category="A"`, 영역: `data-cat="A"` 등으로 정답 매칭
  - `checkCategories()`에서 드롭된 위치와 카테고리 비교

## 4. 에이전트용 도구 생성 프롬프트 템플릿

### 4.1 공통 베이스 프롬프트 (성취기준 → HTML 도구 생성)

아래 템플릿은 위 JSON 중 **하나의 성취기준**을 입력으로 받아, 
해당 `type`에 맞는 HTML 도구를 생성할 때 사용하는 공통 구조입니다.

```text
너는 특수교육 전문가이자 웹 개발자야.
아래 성취기준에 맞는 HTML 학습 도구를 만들어줘.

[성취기준 정보]
- 과목: {{subject}}
- 성취기준 코드: {{code}}
- 성취기준 설명 요약: {{요약된 content (2~3문장)}}

[도구 유형]
- 이 성취기준은 {{type}} 유형(`radio/match/drag/category`)으로 설계할 거야.
- {{type}} 유형의 기본 상호작용은 아래와 같아:
  - radio: 질문 1개 + 보기 3~4개 중 하나 선택, 정답/오답 피드백
  - match: 왼쪽/오른쪽 항목 짝짓기, `data-pair`로 정답 표시
  - drag: 카드 여러 개를 드래그해 올바른 순서/위치로 배열
  - category: 항목을 카테고리 영역으로 드래그해 분류

[기술 요구 사항]
1) 단일 HTML 파일 안에 HTML, CSS, JavaScript를 모두 포함해줘.
2) 외부 라이브러리는 사용하지 말고 순수 HTML/CSS/JS만 사용해.
3) 모바일과 데스크톱에서 모두 보이도록 반응형 레이아웃을 사용해.
4) 버튼과 선택/카드 영역은 손가락으로 누르기 쉽게 충분히 크게 만들어줘.
5) 교사가 나중에 쉽게 수정할 수 있도록, 질문·보기·카드 텍스트·정답 위치 등
   수정 포인트에 한글 주석을 달아줘.

[접근성 요구 사항]
- 글꼴은 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif를 사용해.
- 대비가 높은 색상(흰 배경 + 진한 글자색)을 사용해.
- 키보드(Tab, Enter, Space)로도 조작할 수 있게 해줘.

[화면 구성 기본]
- 상단: "📚 {{subject}}과 학습 도구" 제목
- 그 아래: 성취기준 코드와 짧은 설명 박스
- 중앙: {{type}} 유형에 맞는 상호작용 영역
- 하단: "정답 확인" / "다시하기" 버튼 + 피드백 영역

위 조건을 모두 반영해서 완성도 높은 예시 HTML 파일 코드를 작성해줘.
코드 전체를 ```html 로 감싸지 말고, HTML 원문만 출력해줘.
```

### 4.2 학생 맞춤 리팩터링 프롬프트 (공통)

완성된 HTML 도구를 **특정 학생군**(장애유형/학년/특성)에 맞게 조정할 때 사용하는 공통 템플릿입니다.

## 6. 에이전트가 따라야 할 일반 전략

1. **성취기준 선택**
   - JSON 배열에서 `code` 기준으로 성취기준을 하나 선택한다.
2. **도구 유형 결정**
   - 해당 객체의 `type`(radio/match/drag/category)에 따라 3장의 패턴 중 하나를 따른다.
3. **기본 도구 생성**
   - 4.1 공통 베이스 프롬프트를 사용해 HTML 도구 초안을 생성한다.
4. **학생 맞춤화**
   - 4.2 템플릿으로 장애유형/학년/특성에 맞게 리팩터링한다.
5. **연수/수업용 산출물로 활용**
   - 완성된 HTML은 단일 파일로 저장 → 연수 참가자/교사가 바로 수업에 사용.

이 문서와 `work_movie_에이전트_시스템프롬프트.md`, `work_movie_설계_요약.md`를 함께 주입하면,
에이전트는 **성취기준 → HTML 도구 → 연수/수업 산출물** 전체 흐름을 이해하고 작업할 수 있습니다.
