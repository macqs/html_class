## ⏱️ 2분: 내용 수정하기

### STEP 3-1: 메모장/에디터로 열기

**방법 1 (메모장 - Windows)**:
1. 파일 우클릭
2. "연결 프로그램" → "메모장"

**방법 2 (텍스트 편집기 - Mac)**:
1. 파일 우클릭
2. "다음으로 열기" → "텍스트 편집"

**방법 3 (VSCode - 추천)**:
1. VSCode에서 파일 드래그 앤 드롭

### STEP 3-2: 수정 포인트 찾기
**Ctrl+F (Cmd+F)** 로 검색: `💡 수정 포인트`

### STEP 3-3: 빠른 수정 가이드

#### 📌 선택형 도구 (radio)
```html
<!-- 질문 수정 -->
<div class="question">
    다음 중 동그라미 모양을 찾으세요  ← 이 부분 수정!
</div>

<!-- 선택지 수정 -->
<div class="option" data-correct="false">⬜ 네모</div>
<div class="option" data-correct="true">⚪ 동그라미</div>  ← 정답!
<div class="option" data-correct="false">🔺 세모</div>
```

**✏️ 수정 방법**:
1. 질문 내용만 바꾸기
2. 선택지 내용만 바꾸기
3. 정답은 `data-correct="true"` 유지!

#### 📌 짝짓기 도구 (match)
```html
<!-- 왼쪽 항목 -->
<div class="item left" data-pair="1">사과</div>  ← 내용 수정
<div class="item left" data-pair="2">바나나</div>

<!-- 오른쪽 항목 -->
<div class="item right" data-pair="1">빨간색</div>  ← 내용 수정
<div class="item right" data-pair="2">노란색</div>
```

**✏️ 수정 방법**:
1. 왼쪽/오른쪽 내용만 바꾸기
2. **중요**: `data-pair="1"` 숫자는 짝을 표시! 같은 숫자끼리 정답!

#### 📌 배열형 도구 (drag)
```html
<div class="item" draggable="true" data-order="1">아침</div>
<div class="item" draggable="true" data-order="2">점심</div>
<div class="item" draggable="true" data-order="3">저녁</div>
```

**✏️ 수정 방법**:
1. 항목 내용만 바꾸기
2. **중요**: `data-order="1"` 숫자는 정답 순서!

### STEP 3-4: 저장하기
- **Windows**: Ctrl+S
- **Mac**: Cmd+S

### STEP 4-2: 빠른 테스트

**문제 있으면**:
1. 오타 확인 (특히 따옴표 `"` 빠뜨리지 않았나?)
2. 저장 확인 (파일 저장했나?)
3. 브라우저 새로고침 다시

## 📌 자주 하는 실수 TOP 5

### 1️⃣ 따옴표 빠뜨림
❌ `<div class=option">선택지</div>`
✅ `<div class="option">선택지</div>`

### 2️⃣ 정답 표시 실수
❌ 모든 선택지가 `data-correct="false"`
✅ 정답은 `data-correct="true"`

### 3️⃣ 짝짓기 숫자 안 맞음
❌ 왼쪽 `data-pair="1"` ↔ 오른쪽 `data-pair="2"` (안 맞음!)
✅ 왼쪽 `data-pair="1"` ↔ 오른쪽 `data-pair="1"` (같은 숫자!)

### 4️⃣ 한글 깨짐
❌ 메모장에서 저장 시 인코딩 실수
✅ "다른 이름으로 저장" → 인코딩: **UTF-8** 선택

### 5️⃣ 파일을 저장 안 함
❌ 수정만 하고 저장(Ctrl+S) 안 함
✅ 반드시 저장 후 새로고침!
