# 특수교육용 LLM 프롬프트 템플릿 모음

## 📝 템플릿 사용 가이드

### 기본 원칙
- **구체성**: 학생 특성, 학습 목표, 요구사항 명시
- **단계성**: 복잡한 과제는 단계별로 요청
- **반복성**: 수정 요청 시 이전 결과 기반으로 개선
- **실용성**: 바로 사용 가능한 단일 HTML 파일 요청

### 사용 방법
1. 적절한 템플릿 선택
2. [대괄호] 내용을 실제 상황에 맞게 수정
3. LLM에 입력하여 결과 확인
4. 필요시 수정 템플릿으로 개선
