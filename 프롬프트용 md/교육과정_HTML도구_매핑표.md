## 매핑 개요
2022개정 특수교육 교육과정의 **실제 성취기준 코드와 내용**을 HTML 기반 도구와 연계하여, 특수교사들이 LLM을 활용한 맞춤형 교육 도구를 개발할 수 있도록 지원

### 📚 분석 대상 문서
- **문서명**: (2022개정)+특수교육+교육과정+[별책3]+기본_국가교육위원회+고시+제2024-4호
- **분석 범위**: 
  - 국어과: 63-102페이지 (81개 성취기준)
  - 사회과: 102-137페이지 (50개 성취기준)
  - 수학과: 137-200페이지 (159개 성취기준)
  - 과학과: 200-255페이지 (99개 성취기준)
- **총 성취기준 수**: 389개
- **HTML 도구 매핑 가능**: 약 191개 (49%)

### 🎯 매핑 기준
성취기준에 포함된 **활동 동사**를 기준으로 HTML 도구 유형 분류:
- **선택형**: 선택, 고른다, 구별, 판단, 구분 → 라디오/체크박스 도구
- **배열형**: 배열, 순서, 차례 → 드래그앤드롭 도구
- **분류형**: 분류, 묶는다, 나눈다, 비교 → 정렬/그룹화 도구
- **짝짓기**: 짝지, 연결, 대응, 맞춘다 → 매칭 도구
- **계산형**: 계산, 센다, 더한다, 뺀다 → 연산 도구
